--------- Help ----------------
CC : current control (in red)
MW : mouse wheel
RM: mouse right button
CP : cursor position
-------------------------------
Space	: toggle pause
D	: toggle debug mode
Tab     : toggle simulation view
MW	: Zoom
Esc	: close window
C	: reload config. file
Arrows	: move simulation view
Q	: switch to next control
PageUp/9    : increase CC
PageDown/8  : decrease CC
R	: resets the simulation
         (+ control values to default)
S       : Add a female  scorpion at MP
CTRL-S  : Add a male scorpion
G       : Add a cactus at MP (groves)
L       : add a fermale lizard at MP
CTRL-L  : add a lizard at MP
